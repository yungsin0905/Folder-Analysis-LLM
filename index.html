    Built for teams drowning in paperwork

    Property management firms, law offices, and back-office teams often deal with hundreds of PDFs, scanned contracts, and spreadsheets scattered across folders. Instead of opening each file one by one to copy key details into a spreadsheet, this tool reads the entire folder — including nested subfolders — and lets an AI model pull out the fields that matter, ready to download as a single CSV.

    Frequently Asked Questions

    What file types are supported?

    PDF, Word (.docx), Excel (.xlsx/.xls), and image files (.jpg/.jpeg/.png) are all supported, including scanned documents processed with OCR.

    Does it handle subfolders?

    Yes. Upload the root folder and the tool recursively processes every file inside all subfolders automatically.

    What happens to my files after analysis?

    Files are processed in memory to extract the data you request, and are not stored long-term on the server.

    Do I need to install anything?

    No installation is required — everything runs directly in your browser.

    Stop Analysis?
    Are you sure you want to cancel the analysis? Current progress will be lost.
